# Business Component Development 01 Practicals

This repository contains practical exercises for Business Component Development 01, utilizing the Payara Server and IntelliJ IDE with Java and Maven.

## Project Structure

- `payara-6.2025.11/`: Payara Server installation
- `prac_01/`: First practical exercise (Java Maven project)

## Getting Started

1. Ensure you have Java and Maven installed.
2. Ensure you have Downloaded payara-6.2025.11 to Project directory.
3. Use IntelliJ IDE to open the Maven projects.
4. Start the Payara Server for deployment and testing.
